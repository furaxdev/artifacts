Guide d'installation

Un Windows 10 neuf, déjà à ta main

Réinstaller proprement, en préparant fond d'écran, curseurs et thème sombre avant le premier démarrage, pour ne rien avoir à refaire ensuite. Deux méthodes, dont une qui ne touche pas à l'image du tout.

1Choisis ta route

RouteCommentRisque
A — réponse automatique ISO officielle intacte + Ventoy + un fichier autounattend.xml à la racine de la clé, qui lance ton script au premier démarrage. faible. Rien n'est modifié, on ajoute des fichiers à côté.
B — image retouchée Modifier install.wim (fond, curseurs, ruche de l'utilisateur par défaut) puis reconstruire l'ISO. élevé. Une erreur et l'ISO ne démarre plus. Long.

Le résultat final est identique. Dans les deux cas, ton fond d'écran, tes curseurs et le thème sombre sont en place au premier démarrage, sans que tu touches à rien. La route A y arrive simplement sans risquer ton ISO.

2Route A — la réponse automatique

Windows Setup cherche, sur toutes les clés branchées, un fichier nommé autounattend.xml à la racine. Si il le trouve, il l'applique tout seul. C'est fait pour les administrateurs, et ça marche exactement pareil pour toi.

Ce qu'on met sur la clé

CLE_USB/
  Win10_22H2_French_x64.iso      l'ISO officielle, telle quelle
  autounattend.xml               la reponse automatique
  perso/
    fond.jpg                     ton fond d'ecran
    curseurs/                    tes .cur/.ani
    theme.reg                    theme sombre, fond, curseurs
    installer.cmd                ce qui s'execute au premier demarrage

Le fichier autounattend.xml

Il fait deux choses : il saute les questions du premier démarrage, et il lance ton script une fois la session ouverte.

<?xml version="1.0" encoding="utf-8"?>
<unattend xmlns="urn:schemas-microsoft-com:unattend">
  <settings pass="oobeSystem">
    <component name="Microsoft-Windows-Shell-Setup"
               processorArchitecture="amd64"
               publicKeyToken="31bf3856ad364e35"
               language="neutral" versionScope="nonSxS"
               xmlns:wcm="http://schemas.microsoft.com/WMIConfig/2002/State">
      <OOBE>
        <HideEULAPage>true</HideEULAPage>
        <HideLocalAccountScreen>true</HideLocalAccountScreen>
        <HideOEMRegistrationScreen>true</HideOEMRegistrationScreen>
        <HideOnlineAccountScreens>true</HideOnlineAccountScreens>
        <HideWirelessSetupInOOBE>true</HideWirelessSetupInOOBE>
        <ProtectYourPC>3</ProtectYourPC>
      </OOBE>
      <FirstLogonCommands>
        <SynchronousCommand wcm:action="add">
          <Order>1</Order>
          <Description>Personnalisation</Description>
          <CommandLine>cmd /c for %d in (D E F G H I J) do if exist %d:\perso\installer.cmd %d:\perso\installer.cmd</CommandLine>
        </SynchronousCommand>
      </FirstLogonCommands>
    </component>
  </settings>
</unattend>

La ligne de commande cherche ta clé parmi les lettres de lecteur possibles : elle ne sera pas forcément D: selon la machine.

Le script de personnalisation

@echo off
set PERSO=%~dp0
set DEST=%SystemRoot%\Web\Wallpaper\Perso

mkdir "%DEST%" 2>nul
copy /y "%PERSO%fond.jpg" "%DEST%\fond.jpg" >nul

mkdir "%SystemRoot%\Cursors\Perso" 2>nul
copy /y "%PERSO%curseurs\*.*" "%SystemRoot%\Cursors\Perso\" >nul

reg import "%PERSO%theme.reg"

:: on relance l'explorateur pour que le fond s'applique tout de suite
taskkill /f /im explorer.exe >nul 2>&1
start explorer.exe

Le fichier de registre

Trois réglages, et c'est tout ce qu'il faut pour ce que tu demandes. Les chemins sont ceux de Windows : si tu copies le fond ailleurs, adapte la ligne Wallpaper.

Windows Registry Editor Version 5.00

; --- theme sombre par defaut ---
[HKEY_CURRENT_USER\SOFTWARE\Microsoft\Windows\CurrentVersion\Themes\Personalize]
"AppsUseLightTheme"=dword:00000000
"SystemUsesLightTheme"=dword:00000000

; --- fond d'ecran (10 = remplir l'ecran) ---
[HKEY_CURRENT_USER\Control Panel\Desktop]
"Wallpaper"="C:\\Windows\\Web\\Wallpaper\\Perso\\fond.jpg"
"WallpaperStyle"="10"
"TileWallpaper"="0"

; --- curseurs personnalises ---
[HKEY_CURRENT_USER\Control Panel\Cursors]
"Arrow"="%SystemRoot%\\Cursors\\Perso\\normal.cur"
"Help"="%SystemRoot%\\Cursors\\Perso\\aide.cur"
"AppStarting"="%SystemRoot%\\Cursors\\Perso\\travail.ani"
"Wait"="%SystemRoot%\\Cursors\\Perso\\attente.ani"
"IBeam"="%SystemRoot%\\Cursors\\Perso\\texte.cur"
"Crosshair"="%SystemRoot%\\Cursors\\Perso\\precis.cur"
"Hand"="%SystemRoot%\\Cursors\\Perso\\main.cur"
"No"="%SystemRoot%\\Cursors\\Perso\\interdit.cur"
"SizeNS"="%SystemRoot%\\Cursors\\Perso\\vertical.cur"
"SizeWE"="%SystemRoot%\\Cursors\\Perso\\horizontal.cur"
"SizeNWSE"="%SystemRoot%\\Cursors\\Perso\\diag1.cur"
"SizeNESW"="%SystemRoot%\\Cursors\\Perso\\diag2.cur"
"SizeAll"="%SystemRoot%\\Cursors\\Perso\\deplacer.cur"

Les noms de fichiers .cur et .ani doivent correspondre à ce que tu mets dans le dossier curseurs. Le registre applique aux sessions suivantes ; le script relance l'explorateur pour que ce soit immédiat.

Dans un fichier .reg, un antislash se double. Les lignes ci-dessus sont correctes pour un fichier .reg — copie-les telles quelles.

3Route B — retoucher l'image

C'est ce que tu décrivais : modifier install.wim pour que tout soit cuit dans l'installation. C'est faisable depuis Arch, avec trois outils.

sudo pacman -S wimlib libisoburn chntpw
# wimlib   : lire et modifier install.wim
# xorriso  : reconstruire l'ISO (paquet libisoburn)
# chntpw   : editer une ruche de registre Windows

1. Sortir le contenu de l'ISO

mkdir -p ~/win/iso
bsdtar -xf ~/Win10.iso -C ~/win/iso
ls ~/win/iso/sources/install.wim
# si tu vois install.swm a la place, l'image est decoupee : prendre l'ISO 64 bits
# officielle non modifiee, elle contient un install.wim d'un seul morceau

2. Regarder les editions disponibles

wimlib-imagex info ~/win/iso/sources/install.wim
# repere l'index de Windows 10 Pro, par exemple 6

3. Ajouter tes fichiers dans l'image

sudo wimlib-imagex update ~/win/iso/sources/install.wim 6 \
  --command="add ~/perso/fond.jpg /Windows/Web/Wallpaper/Perso/fond.jpg" \
  --command="add ~/perso/curseurs /Windows/Cursors/Perso"

4. Modifier la ruche de l'utilisateur par défaut

C'est la partie maligne : les réglages de thème, de fond et de curseurs sont des réglages par utilisateur. Les écrire dans le profil par défaut fait qu'ils s'appliquent à tout nouveau compte, donc au tien dès la première ouverture de session.

wimlib-imagex extract ~/win/iso/sources/install.wim 6 \
  --dest-dir=/tmp/hive "/Users/Default/NTUSER.DAT"

sudo chntpw -e /tmp/hive/NTUSER.DAT
# dans l'invite :
#   cd Software\Microsoft\Windows\CurrentVersion\Themes\Personalize
#   ed AppsUseLightTheme        -> 0
#   ed SystemUsesLightTheme     -> 0
#   cd \Control Panel\Desktop
#   ed Wallpaper                -> C:\Windows\Web\Wallpaper\Perso\fond.jpg
#   ed WallpaperStyle           -> 10
#   q  (quitter en enregistrant)

sudo wimlib-imagex update ~/win/iso/sources/install.wim 6 \
  --command="add /tmp/hive/NTUSER.DAT /Users/Default/NTUSER.DAT"

5. Reconstruire l'ISO amorçable

C'est l'étape qui casse tout si elle est ratée. Les options qui suivent produisent une ISO qui démarre en UEFI comme en ancien mode.

xorriso -as mkisofs \
  -iso-level 3 -udf -J -joliet-long -l -D -relaxed-filenames \
  -b boot/etfsboot.com -no-emul-boot -boot-load-size 8 \
  -eltorito-alt-boot -e efi/microsoft/boot/efisys_noprompt.bin -no-emul-boot \
  -V "WIN10_PERSO" \
  -o ~/Win10-perso.iso ~/win/iso

-udf est indispensable : install.wim dépasse 4 Go, et le format ISO classique ne sait pas gérer un fichier de cette taille. C'est l'erreur qui donne une ISO qui se construit puis refuse de s'installer.

Vérifier avant de graver

xorriso -indev ~/Win10-perso.iso -report_el_torito plain
# doit lister deux entrees de demarrage : une BIOS (etfsboot) et une UEFI (efisys)

4Ce que je te conseille

  • Commence par la route A. Elle donne le même résultat, elle se teste et se corrige en trente secondes — tu changes le .reg, tu réessaies. La route B demande une reconstruction d'ISO à chaque essai.
  • Passe à la route B seulement si tu veux que le fond soit là dès l'écran de création du compte, ou si tu prévois d'installer la même chose sur plusieurs machines.
  • Dans les deux cas, garde l'installation officielle : ton activation Pro suit le matériel et se refera seule.

À vérifier avant de commencer

  • Mon fond d'écran et mes curseurs sont prêts, sur la clé
  • Les noms de fichiers dans theme.reg correspondent à mes curseurs
  • L'ISO vient bien de microsoft.com
  • J'ai sauvegardé, et je sais repérer la partition EFI sans y toucher
