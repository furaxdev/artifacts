Guide d'installation

Installer un Windows 10 propre

Remplacer un Windows fatigué par une installation officielle, neuve, activée — et garder Arch dans le menu de démarrage. Objectif : un Windows qui sert à ce que Arch ne sait pas faire, Roblox en tête.

1Ce qui change par rapport à Tiny10

Ton activation suit. Ton Windows 10 Pro actuel est activé, et sur Windows 10 l'activation est liée au matériel de la machine. En réinstallant la même édition sur le même PC, il se réactive tout seul, sans rien saisir. C'est exactement ce que Tiny10 ne permettait pas, puisqu'il est basé sur LTSC.

Windows 10 n'a plus de mises à jour de sécurité gratuites depuis octobre 2025. Pour du jeu et un usage courant, ça reste parfaitement utilisable — mais garde en tête que ce n'est plus un système maintenu.

Quant à Windows 11 : il ne s'installera pas officiellement sur cette machine (mémoire et processeur trop anciens). Windows 10 est le bon choix ici.

2Télécharger l'ISO officielle

Une astuce qui vaut la peine d'être connue : depuis Arch ou ton Mac, la page de Microsoft propose directement le fichier ISO. Depuis Windows, la même page ne propose que l'outil de création, qui ne sait pas sortir un ISO.

Page officielle à ouvrir depuis Arch

microsoft.com/fr-fr/software-download/windows10ISO

Choisis : Windows 10, version 22H2, 64 bits, français. Compte environ 5,8 Go.

Si la page te propose l'outil de création au lieu de l'ISO, c'est que ton navigateur se fait passer pour Windows : ouvre-la depuis Arch, ou depuis le Mac.

N'utilise que cette source. Les ISO Windows qui traînent sur les sites de téléchargement sont régulièrement modifiées. Le fichier officiel, c'est celui-là, et rien d'autre.

3Avant d'écraser : sauvegarde et pilotes

La carte graphique d'abord. C'est elle qui fait tourner Roblox, et sans pilote tu te retrouves avec un affichage lent et des jeux injouables. Télécharge-la avant, depuis Arch, ainsi que le chipset, le réseau et le son. Tu les mettras sur la clé USB.

Sauvegarde ensuite tout ce que tu veux garder de ton Windows actuel sur un disque externe. Et si tu veux pouvoir revenir en arrière, fais une image de la partition avec Clonezilla.

5La clé USB

Ventoy, comme toujours : tu l'installes une fois, puis tu copies simplement le fichier ISO dessus.

sudo pacman -S ventoy          # ou : yay -S ventoy
lsblk                          # repère ta clé, par exemple /dev/sdc
sudo ventoy2disk /dev/sdc      # installe Ventoy sur la clé — EFFACE la clé
sudo mount /dev/sdc1 /mnt/cle
sudo cp Win10*.iso /mnt/cle/
sudo cp -r pilotes /mnt/cle/   # ce que tu as téléchargé à l'étape 3
sync
sudo umount /mnt/cle

Pas de dd. Une ISO Windows écrite ainsi ne démarre pas. Et pas de Rufus depuis Arch non plus : Ventoy est la voie simple.

6Installer

  1. Redémarre, ouvre le menu de démarrage (F12, F2, F10 ou Échap), choisis la clé en mode UEFI.
  2. Prends Personnalisée, jamais « Mettre à niveau ».
  3. Supprime la partition « Réservé au système », la NTFS principale, puis la partition de récupération.
  4. Sélectionne l'espace non alloué, clique Suivant.

Si Windows parle de MBR ou de GPT, tu as démarré la clé en mode hérité. Recommence en choisissant l'entrée UEFI.

7Après l'installation

  1. Vérifie l'activation : Paramètres, Mise à jour et sécurité, Activation. Ça doit indiquer que Windows est activé, tout seul.
  2. Les pilotes : chipset, carte graphique, réseau, son. Redémarre entre les étapes si on te le demande.
  3. Les mises à jour Windows : lance-les, elles fonctionnent normalement sur une ISO officielle.
  4. Roblox : va sur roblox.com et prends l'installateur. Il réclame sa propre mise à jour au premier lancement, c'est normal.

8Remettre Arch dans le menu de démarrage

Après l'installation, Windows passe en premier et démarre à ta place. Redémarre, choisis l'entrée Linux dans le menu du firmware, puis dans Arch :

sudo os-prober
sudo grub-mkconfig -o /boot/grub/grub.cfg

L'entrée Windows revient dans GRUB. Si os-prober ne trouve rien, vérifie cette ligne dans /etc/default/grub :

GRUB_DISABLE_OS_PROBER=false

À vérifier avant de commencer

  • Mes fichiers Windows sont copiés ailleurs
  • Le pilote de la carte graphique est téléchargé, sur la clé
  • L'ISO vient bien de microsoft.com
  • J'ai repéré mes partitions, et je sais reconnaître la EFI
  • Je sais démarrer la clé en mode UEFI
  • Mon Windows actuel est bien activé (ça garantit que le nouveau le sera)
